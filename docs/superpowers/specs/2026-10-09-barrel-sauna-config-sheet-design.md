# バレルサウナ仕様確認書アプリ 設計書

- 作成日：2026-10-09
- ステータス：承認済み（2026-10-09）

## 1. 目的・利用シーン

Web会議の商談中、営業担当が画面共有しながらお客様と製品仕様を相互確認し、選択結果を「バレルサウナ仕様確認書」としてPDF出力する。

- **金額は扱わない**（仕様確認専用の書類。見積金額は別途作成）
- 利用者：Rink SAUNA の営業担当（操作）、お客様（画面共有で閲覧）

### 成功基準

- 何もインストールせず、HTMLファイルをブラウザで開くだけで使える
- 画面共有越しでもお客様が読める文字サイズ・操作の分かりやすさ
- 最大5仕様を1通の確認書にまとめ、A4縦のPDFとして保存できる
- 日本語が崩れずに印刷される

## 2. 方式

- **単一HTMLファイル**（HTML/CSS/JavaScript をインライン、外部ライブラリ・サーバー不要、オフライン動作）
- ロゴ画像は Base64 で HTML に埋め込む（元画像：`assets/rink-sauna-logo.png`）
- PDF出力はブラウザの印刷機能（`window.print()`）＋印刷用CSS（`@page { size: A4 portrait }`）
- 対象ブラウザ：Google Chrome 最新版

## 3. 画面構成

```
┌──────────────────────────────────────────────┐
│ [ロゴ] バレルサウナ仕様確認書   [新規作成] [PDF出力] │
├──────────────────────┬───────────────────────┤
│ 共通情報               │                       │
│  日付 / お客様名 / 担当者名 │   A4プレビュー          │
│ [① ][② ][＋仕様を追加]    │   （入力に即時連動）       │
│  仕様名・各項目          │                       │
│  [この仕様を複製][削除]    │                       │
│ 事前確認事項（全体で1回）    │                       │
└──────────────────────┴───────────────────────┘
```

- 左：入力フォーム（スクロール）、右：A4プレビュー（スクロール）
- 画面幅が狭い場合はプレビューを下に回す
- 文字は大きめ（本文16px以上）、選択肢はタップしやすい大きさ
- 配色：ブランドカラー（茶 `#4B2721`、金 `#C9A80A`、緑 `#5FBF62`）をヘッダー・アクセントに使用。PDF本文は白背景・黒文字

### 3.1 共通情報

| 項目 | 入力 | 備考 |
|---|---|---|
| 日付 | 日付入力 | 初期値は当日。PDFでは「YYYY年M月D日」 |
| お客様名（個人・会社名） | テキスト | 初期値は空欄 |
| 担当者名 | テキスト | |

### 3.2 仕様タブ

- 初期状態は仕様①のみ。「＋仕様を追加」で最大⑤まで
- タブごとに「この仕様を複製」（新しいタブに内容をコピー）と「削除」（確認ダイアログあり、最後の1つは削除不可）
- 削除後は番号を詰め直す（①②③…は常に連番）
- 5つに達したら「＋仕様を追加」と「複製」を無効化

### 3.3 各仕様の入力項目

| 項目 | 入力形式 | 選択肢 |
|---|---|---|
| 版 | 初版／更新版＋数字（−／＋で1〜99） | 仕様ごと。初期値は初版。複製時は元の版をコピー |
| 仕様名 | 自動（入力欄なし） | 「日付(YYYYMMDD)_お客様名_都道府県_バレルサウナ規格_仕様①_版」。未入力の部分は省く |
| バレルサウナ規格 | 単一選択 | i – barrel Tiny R12 / Small R15 / Small-Long R18 / Medium R245（軒あり） / Medium-Long R275（軒あり） / Large R35（軒あり・前室あり） / Large R38（軒あり・前室あり） / Large R40（軒あり・前室あり） |
| 仕様変更オプション | 複数選択 | 前室（1,050mm延長）／二重扉 / 軒延長（+400mm）・外椅子・外灯 / 直径変更 1,800mm→2,050mm |
| バレルサウナ規格 特記事項 | テキストエリア | |
| 屋根材（ルーフィング・アスファルトシングル） | 単一選択 | あり / なし |
| 塗装（2度塗）防腐防虫施工 | 単一選択 | あり / なし |
| ひのき円形水風呂 | 単一選択 | あり（チラーなし） / あり（チラーあり） / なし |
| オプション窓ガラス | 複数選択 | 大窓：背面 強化ガラス窓（1枚） / 縦長窓：強化ガラス窓（2枚） 前面 / 縦長窓：強化ガラス窓（2枚） 背面 / 横長窓：腰位置・側面 強化ガラス窓（2枚） / 半円パノラマ 強化ガラス窓（1枚） |
| 組立施工 | 単一選択 | 現地 組立作業・屋根施工（平日） / 現地 組立作業・屋根施工（休日） / 工場 組立作業・屋根施工 / なし（セルフビルド） |
| 熱源 | 単一選択 | HARVIA WALL4.5（4.5kW）+遮熱板（小） / HARVIA WALL6（6kW）+遮熱板（小） / HARVIA WALL8（7.4kW）+遮熱板（小） / HARVIA KIP6（5.5kW）+遮熱板（小） / HARVIA KIP8（7.4kW）+遮熱板（小） / HARVIA SPIRIT6（6kW）+遮熱板（小） / HARVIA SPIRIT9（9kW）+遮熱板（小） / ガスストーブ（7kW）+遮熱板（小） / 薪ストーブM3（16.5kW）+遮熱板（大） / その他 |
| 熱源（その他の内容） | テキスト | 熱源で「その他」選択時のみ表示 |
| 2次側電気工事 | 単一選択 | Rink対応 / なし（お客様対応） |
| 配送先 | プルダウン | 北海道〜沖縄の47都道府県 / 配送なし |

| オプション製品 | 複数選択 | スピーカー・アンプ / ロウリュセット / アンカー固定 / 排水口設置 / 入口扉 仕様変更（窓ガラス扉 → 木製扉への変更） |

- 項目数が少ない単一選択（2〜4択）はボタン型（セグメント）、規格・組立施工・熱源・配送先はプルダウン、複数選択はチェックボックス型のボタン
- 規格選択時、規格名に含まれる標準装備（軒あり／前室あり）を補足表示

### 3.4 事前確認事項（確認書全体で1回）

各項目に「はい／いいえ」の単一選択。

1. **電気工事について**：見積に記載がない場合、お客様手配にて一次側/二次側電気工事、照明電気配線(100V)の手配が必要となります。
2. **二次側電気工事について**：二次側電気工事前までに、一次側電気工事を完了させておく必要があります。
3. **バレルサウナ設置基礎について**：設置日までに、水平の取れた基礎（コンクリート基礎など）を事前準備が必要です。
4. **配送について**：ユニック車が入るスペースや上空の障害物（電線・木・壁など）の事前確認が必要です。
5. **商用利用時の手続きについて**：商用でサウナ設置される場合は、お客様にて消防と保健所等へ手続きが必要です。※(法人・個人を問わず)プライベート利用の場合は必要ありません。※手続きは、原則お客様(もしくは依頼業者)にて行なって頂く必要があります。

## 4. PDF（印刷）レイアウト

- A4縦、余白 15mm 程度
- **各ページ共通ヘッダー**：ロゴ（右上）、表題「バレルサウナ仕様確認書」、日付、お客様名、担当者名。1仕様が2枚にまたがる場合も、各用紙にヘッダーと仕様名を繰り返す
- **仕様ページ**：1仕様 = 1ページ。見出し「仕様①：{仕様名}」＋項目名／選択内容の2列表
  - 規格が未選択の仕様は出力しない
  - 未選択の項目は「—」
  - 複数選択は改行区切りで列挙
- **最終ページ**：事前確認事項（項目文＋「はい／いいえ」、未回答は「—」）
- フッター：ページ番号（用紙ごとの通し番号 n / N）。会社連絡先は今回入れない（ロゴのみ）
- 印刷時はフォーム・ボタン類を非表示にし、プレビュー部分のみ出力
- 全仕様の規格が未選択の場合、PDF出力ボタン押下時に警告を出す
- PDFのファイル名（印刷時の文書タイトル）は仕様名。印刷する仕様が複数の場合は先頭の仕様の内容に仕様番号を並べる（例：`20261009_山田商事_千葉県_i – barrel Large R35（軒あり・前室あり）_仕様①③_初版`、版は先頭の仕様のもの）。ファイル名に使えない文字 `\ / : * ? " < > |` は `-` に置き換える

## 5. データ・状態管理

- 選択肢定義はスクリプト先頭の定数オブジェクト（`OPTIONS`）に集約し、項目追加・文言変更はそこだけで済むようにする
- 状態：`{ date, customerName, contactName, specs: [Spec ×1〜5], checks: {...}, activeIndex }`
- 入力のたびに `localStorage` へ自動保存し、再読込時に復元（失敗時は無視して初期状態）
- 「新規作成」：確認ダイアログ後に状態を初期化（日付は当日）

## 6. エラー・端の扱い

- localStorage が使えない環境（プライベートブラウズ等）でも動作する（保存されないだけ）
- 選択肢定義が変わり保存値が存在しない場合、その値は未選択扱い
- 仕様5つで追加・複製を無効化、最後の1仕様は削除不可

## 7. テスト

- 状態ロジック（追加／複製／削除／番号詰め／配送なし時の配送方法クリア／空仕様の除外）は純粋関数に分離し、ブラウザで開くテストページ（`tests.html`）で検証
- 手動確認：Chrome で全項目入力 → PDF保存し、ページ分割・日本語表示・ロゴ・未選択「—」を目視確認

## 8. スコープ外

- 金額・見積計算
- サーバー保存、案件履歴、複数PC間の共有
- PDFの直接ダウンロード（印刷ダイアログ経由のみ）
- 会社連絡先のフッター表記（必要になれば追加）
